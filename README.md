# MVICH: Multi-View Invariant Context Hypergraph Learning for Cross-Project Defect Prediction

This repository provides the official replication package for MVICH, a
multi-source cross-project defect prediction framework that discovers
project-balanced local contexts, examines their transferability through
complementary semantic metric views and the complete metric space, and
represents supported source--target contexts using a weighted context
hypergraph.

The repository contains the datasets, preprocessing procedures, MVICH
implementation, comparison methods, controlled variants, experimental
scripts, statistical analyses, figures, and results required to reproduce
the experiments reported in the paper.
